# Sprint_5 — UI тесты Stellar Burgers (Chrome)

## Описание
Проект содержит Selenium+pytest тесты для проверки функционала сайта Stellar Burgers:
- Регистрация
- Вход (несколько сценариев)
- Переход в Личный кабинет
- Переход в Конструктор
- Выход из аккаунта
- Проверка вкладок конструктора (Булки, Соусы, Начинки)
